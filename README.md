## Veröffentlichung über GitHub Pages
1. Neues öffentliches Repository anlegen.
2. Alle Dateien aus dem entpackten Ordner hochladen.
3. Settings → Pages öffnen.
4. Branch `main` und Ordner `/root` auswählen.
5. Optional `xorviq.com` als Custom Domain verbinden.

## Vor dem Livegang
- Telefonnummer und persönliche Daten ergänzen.
- E-Mail-Adresse testen.
- Instagram-Benutzername prüfen.
- Impressum und Datenschutz rechtssicher vervollständigen.
- Marken- und Namensprüfung abschließen.
