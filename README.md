# XORVIQ – Bald verfügbar

Diese Website zeigt ausschließlich geplante zukünftige Leistungen.

## Upload
1. ZIP entpacken.
2. Alle Dateien und den Ordner `assets` in GitHub hochladen.
3. Vorhandene Dateien ersetzen.
4. `Commit changes` klicken.
5. 1–3 Minuten warten.

Wichtig: Impressum und Datenschutz enthalten Platzhalter und müssen rechtlich geprüft werden.
