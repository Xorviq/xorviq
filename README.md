## GitHub Upload
1. ZIP entpacken.
2. Im Repository `Add file` → `Upload files`.
3. Den vollständigen Inhalt dieses Ordners hochladen.
4. Vorhandene Dateien mit gleichem Namen ersetzen.
5. `Commit changes` klicken.
6. 1–3 Minuten warten und die Seite mit hartem Reload aktualisieren.
